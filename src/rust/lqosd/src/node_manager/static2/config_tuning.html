DPDK Dataplane
The DPDK pipeline owns the dataplane ports (the PMD owns the NIC), so most of this is informational and read-only. Only the boot worker count is editable.
Applies after the next libreqos-setup run (the plan/env writer renders [queues] workers into LIBREQOS_DPDK_WORKERS) and a libreqos-bridge restart — not a restart alone. Leave blank to let the installer derive it.
The EAL lcore set remains authoritative; this value sizes the worker pool and defaults the RX/TX queue counts. The panel's boot value (LIBREQOS_DPDK_WORKERS) is shown read-only and can legitimately differ from this configured value until the installer re-renders the environment.
